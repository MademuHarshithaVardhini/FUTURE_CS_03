# API Security Risk Analysis

## Objective
To analyze API security risks using ethical and read-only testing methods.

---

## API Tested
JSONPlaceholder  
https://jsonplaceholder.typicode.com

---

## Tools Used
- Kali Linux
- Postman
- Browser Developer Tools

---

## Methodology
- Reviewed API endpoints
- Tested endpoints using Postman
- Analyzed responses and headers
- Identified security risks
- Classified severity levels
- Suggested remediation steps

---

## Key Findings
- Unauthenticated Access
- Broken Authorization
- Excessive Data Exposure
- Lack of Rate Limiting
- Weak Input Validation

---

## Risk Levels
- High: Critical security issues (Authentication & Authorization)
- Medium: Data exposure & rate limiting issues
- Low: Input validation weakness

---

## Deliverables
- API Security Risk Analysis Report (PDF)
- Screenshots of testing and results

---

## ⚠️ Ethical Note
This project was conducted using a public test API in a read-only environment. No exploitation or harmful activity was performed.
